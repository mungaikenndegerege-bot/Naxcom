# Naxcom Mobiles

Static shop operations app for Naxcom Mobiles, published with GitHub Pages.

## Live app

After the first successful deployment, open <https://mungaikenndegerege-bot.github.io/Naxcom/>.

## Deployment

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes the repository on each push to `main`. In the repository's **Settings → Pages**, set the source to **GitHub Actions**.

## Data

The app currently stores data in this browser. Records are not shared across browsers or devices. Export backups regularly from the app and keep them private.
